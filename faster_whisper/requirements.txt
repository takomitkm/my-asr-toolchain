# ==================== GPU 这一档还要的东西（pip 装不到，看这里）====================
#
# ctranslate2 4.x 的 CUDA 后端在运行时找 cuDNN 9 + cuBLAS 12，必须是【进程能搜到的位置】。
# 作者机上是装在 Windows 系统目录（System32） 的（随 NVIDIA CUDA Toolkit / cuDNN 安装包进去的），
# 没有装 nvidia-cudnn-cu12 / nvidia-cublas-cu12 这两个 pip 包。
# 两条路任选：
#   A) 装 NVIDIA 官方 cuDNN 9 + CUDA 12 运行库（要登录，没有匿名直链 → assets.json 里
#      那条 manual 只能给人工，--check 对它只给 WARN）。
#   B) pip install nvidia-cudnn-cu12 nvidia-cublas-cu12，再把 site-packages\nvidia\*\bin
#      加进 PATH（或按 ctranslate2 文档用 --extra-index-url 那套）。
# 注意别和 CrispASR 的 GPU 档混：本仓 CrispASR-FireRed/ 和 CrispASR-Qwen/ 用的 cublas64_12.dll
# 是 CrispASR release 附带的那三件（113,712,640 B），和 System32 里这套（113,716,224 B）
# 差 3,584 B，不是同一版。
#
# 【B 级，未在这台机器上核过】Linux 上 PyPI 默认轮子的 ctranslate2 可能是 CPU 构建，
# 要在 Linux 上吃 CUDA 得按 ctranslate2 自己的发布说明取对应构建；这台机器只跑过 Windows。
# 纯 CPU 的机器请直接用仓库 cpu 分支，不要靠这条链跑 GPU 档。

# rules.example.txt —— 转写后处理规则示例（不是产线在用的那份）
#
# 这一环在链路里的位置：AED 出原始文本 -> 去空行/逐行 strip -> 复读折叠
# （remove_repetitions：短串重复 6 次以上、长串重复 4 次以上折成一次，再加相邻重复行去重）
# -> 本文件的规则逐条 re.sub -> 写进 <out-dir>\<组名>.txt。
# 规则文件不存在时不清洗、不报错（xhs-chain-cpu.py load_rules 只写一行 info）。
#
# 格式（照 load_rules 的实现写，别照别家的规则文件猜）：
#   · 每行一条，第一个 "=" 左边是正则、右边是替换；替换取 "=" 右侧全部再 strip。
#   · 删掉命中的内容就写 "正则=" （右侧留空）。
#   · "#" 开头是注释，空行跳过；BOM 会被 utf-8-sig 吃掉。
#   · 单条正则非法只跳过那一行并写 warning，整份文件不会失效。
#   · 正则里不能出现 "=" 字面量（第一个 = 就是分隔符，转义也躲不过 split）。
#     确实要匹配等号，用十六进制写法 \x3d。
#   · 匹配作用在整段文本上，但没开 MULTILINE：^ 和 $ 只认整段的首尾，
#     . 也不跨行；要跨行自己写 [\s\S]。
#   · 规则按文件顺序逐条生效，前一条的产物会被后一条再匹配一遍。
#
# 下面的条目是示例，用来告诉你形状；每条都能安全空转（匹配不到就不改文本）。
# 真正该往里放的是你在自己语料上反复看到的那几类错：固定的幻听短语、
# 品牌/人名被写成同音字、台标口播被唱进正文。

# --- 1) 整段幻听：命中即删 ---
(谢谢|感谢)(大家|各位)?(观看|收听|点赞)=
(关注|订阅)(我|本频道|主播)(不|走)?(迷路)?=

# --- 2) 标点被吐成空格/重复：压成单个 ---
[，。]{2,}=。
[！？]{2,}=？
(\s\s)=

# --- 3) 同音错字（示例，换成你自己的词表）---
帐号=账号
登陆=登录

# --- 4) 需要"等号"本身参与匹配时 ---
价格\x3d[0-9]+元=

# 关于 onnxruntime 的版本，两条互相独立的事实，别混：
#   1) 1.20.1 的 contrib 只实现了 4-bit MatMulNBits，所以公开的 punc.q8w.onnx
#      在 1.20.1 上加载会报 "Only 4b quantization is supported"。本包的解法不是升 ORT，
#      而是 fetch_assets.py 用 dequant_punc.py 把它逆量化成纯 f32（普通 MatMul）。
#   2) ORT>=1.21 在部分 Windows 机器上 import 就崩（0xC0000142 / "DLL 初始化例程失败"），
#      根因是 System32 的 VC 运行库太旧、缺 vcruntime140_threads.dll，与 ORT 本身无关。
#      1.20.1 是唯一"只装包就能起"的版本，所以这里钉它。
# 装 1.20.1 就别指望跑 crispasr / torch 导出，那两条要单独的 torch 环境。
